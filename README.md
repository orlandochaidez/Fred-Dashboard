 Better FRED — Full Edition

Mobile-first FRED dashboard with charts, multi-series comparison, units selector, named watchlists, release calendar, and polished PWA support.

## Features
- **Popular tab** — key rates with sparklines, live values, and update metadata
- **Watchlists** — create named lists, add series from anywhere, delete lists
- **Search** — full FRED text search
- **Compare mode** — select multiple series (tap Compare, then cards) and overlay them on one chart
- **Units selector** — on any chart switch between Levels, YoY %, % Change, Change (FRED computes the transform)
- **Release calendar** — recent updates and observation ends for popular series
- **Charts** — smooth Lightweight Charts, range buttons, multi-series colors
- Dark / light mode
- **PWA** — proper icons, Add to Home Screen, smarter caching (network-first for API data)

## Setup
1. Get a free API key: https://fredaccount.stlouisfed.org/apikeys
2. Open `index.html` or host the folder
3. Paste your key when prompted

## Hosting on GitHub Pages
Upload the whole folder (`index.html`, `manifest.json`, `sw.js`, icons, README) to a public repo → Settings → Pages → main / root.

## Tips
- Use Compare mode for overlays (e.g. 10Y vs Fed Funds vs Mortgage).
- Units selector is powerful for inflation series (switch CPI between levels and YoY).
- Watchlists persist in your browser.
